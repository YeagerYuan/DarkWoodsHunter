# DarkWoodsHunter

这是一款以黑暗森林为主题的第一人称射击游戏。目前的版本提供一个单人射击练习场，可以试用 AK-47、USP-S 和 M9 刺刀。

## 在本机运行

1. 安装 Unreal Engine 5.8、带 C++ 游戏开发组件的 Visual Studio，以及 Git LFS。
2. 在命令行运行 `git lfs install`，再克隆本仓库。若已克隆，在仓库目录运行 `git lfs pull` 下载关卡和素材。
3. 打开 `DarkWoodsHunter.uproject`。若编辑器提示重建项目模块，选择重建。
4. 默认打开 `Lvl_ClassicRange`。点击编辑器中的「播放」进入练习场。

`1` / `2` / `3` 切换武器，左键攻击，右键装卸 USP 消音器或用 M9 重刺，`R` 换弹，`F` 检视。练习场内的靶子会自动复位。
